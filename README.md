# GO TIRANA

City guide and bus planner for Tirana, in English, Italian and Albanian.

Live: https://isuf743.github.io/go-tirana/

- `burimi_faqes/`: sources (templates, texts, places, bus data)
- `scripts/03_nderto_faqen.py`: builds the static pages (`python scripts/03_nderto_faqen.py`)
- `planner/`: the bus planner

The contact and newsletter forms need PHP, so they only work on a PHP host, not on GitHub Pages.
